# Modern Requirements for DevOps: Product Overview

- A requirement management platform, not a project management tool
  - Works as a native extension inside Azure DevOps
  - Four products: Modern Requirements for DevOps, Copilot for DevOps, Agent for DevOps, AI Synergy
  - Focus for now: Modern Requirements for DevOps and Copilot for DevOps only
- Difference from project management tools (Jira, ClickUp):
  - Project management: work items, user stories, to-do/in-progress/done workflows
  - Requirement management: requirements derived from compliance/regulatory standards

# Regulatory Industries and Compliance Standards

- Regulatory industries: healthcare, aerospace, banking, railway, government, energy, automotive, etc.
- Compliance standards are mandatory rules to prevent failures that could harm or kill people
  - Example: DO-178C, the primary guideline for commercial aircraft software (FAA/EASA approval)
  - Medical device example: wrong thermometer reading leads to wrong treatment
- Regulatory bodies audit compliance before a product can go to market
- Candidate asked to research: compliance standards and regulatory standards

# Key Features of Modern Requirements for DevOps

- Traceability Matrix:
  - Links epics, features, user stories, and test cases end-to-end
  - Two types: horizontal (epics to features to user stories) and intersectional (coverage across requirements)
  - Ensures regulatory requirements (e.g., DO-178C rules) are covered by features/user stories
- Smart Docs:
  - Creates living requirement documents (FRD, NFR, PRD) directly inside Azure DevOps
  - Requirements dragged in from Azure DevOps auto-update in the document when changed
- Work item hierarchy: Epic (high-level business goal) → Feature → User Story → Test Case
